# Code and data availability (draft statement for the paper)

The source code of YourArogyum, the data-generation and training script for the synthetic risk models, and all experiment scripts and result files are available at https://github.com/WeatherForecaster/YourArogyum (branch `main`; paper results correspond to the commit tagged by the authors at submission). The risk models are trained on synthetic data generated by `ml-service/train_model.py` with fixed seeds. The real-data experiment uses the publicly available Pima Indians Diabetes Database (original owner: National Institute of Diabetes and Digestive and Kidney Diseases), downloaded at run time and not redistributed. Chatbot evaluation logs: [to be added when the evaluation is done]. No patient data were collected.
